# Excel Data Analysis Project

## Project Overview
This project demonstrates data cleaning, analysis, and visualization using Microsoft Excel.

The dataset was prepared and transformed into a structured format to generate insights and support data-driven decision making.

## Skills Demonstrated
- Data cleaning in Excel
- Removing duplicates
- Handling missing values
- Using formulas and functions
- Creating pivot tables
- Data visualization using charts

## Tools Used
- Microsoft Excel

## Key Insights
- Identified trends and patterns in the dataset
- Summarized data using pivot tables
- Created visual charts to communicate findings clearly
